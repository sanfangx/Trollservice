# TrollService

适用于 iOS (TrollStore) 的后台服务与命令行程序管理工具。

在安装了 TrollStore 的 iOS 设备上，提供图形化界面来安装、管理和运行各类单二进制后台程序（如 AIStudio2API、Alist 等），免去在终端中手动签名和配置的繁琐操作。

---

## 核心功能

* **安装与自动配置**  
  支持导入可执行文件一键安装，自动配置免沙盒及运行所需权限；提供预设模板，支持自定义环境变量与权限配置文件（Entitlements）。
* **无损更新**  
  更新程序版本时仅替换可执行文件，自动保留原有的配置文件（`.env`）、数据文件和数据库，不会因升级导致数据丢失。
* **后台常驻运行**  
  支持在界面中随时启动和停止服务。服务运行脱离前台界面，划掉管理应用或设备锁屏后仍可保持后台运行。
* **状态与日志查看**  
  实时显示服务运行状态（进程 PID、内存占用、运行时长）以及端口监听情况；内置日志查看器，便于随时排查运行错误。

---

## 数据存放规范

所有受管服务统一安装在以下目录，便于使用 Filza 查看或备份：

```text
/var/mobile/Documents/service/<服务标识>/
├── bin/                 # 可执行文件（更新时仅替换此处）
├── config/              # 配置文件与权限文件（.env、entitlements.plist）
└── runtime/             # 运行日志（stdout.log）与程序生成的数据/数据库
```

## 使用说明

### 1. 安装应用
在 [Releases](https://github.com/sanfangx/Trollservice/releases) 下载最新的 `TrollService.tipa`，通过 TrollStore 打开并安装。

### 2. 添加服务
1. 打开 TrollService，点击右上角 **「+」**。
2. 选择预设模板（或直接输入程序标识与名称）。
3. 选择待安装的 ARM64 二进制文件。
4. 按需配置环境变量或自定义权限，点击 **「立即安装并自动签名赋权」**。
5. 在主界面开启服务即可。

### 3. 更新服务
当程序有新版本时，在主界面点击对应服务的 **「更新 / 配置」**，选择新版二进制文件更新即可。程序更新后将自动重签并恢复运行，原数据完好保留。
